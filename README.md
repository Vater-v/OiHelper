# OiHelper

**Версия:** 8.39

OiHelper — это утилита для Windows, предназначенная для автоматизации и помощи в управлении игровыми клиентами онлайн-покера. Она предоставляет оверлей-интерфейс (на PyQt6) для управления окнами, автоматического выполнения рутинных задач и мониторинга сессий.

Приложение активно использует системные функции Windows и компьютерное зрение (OpenCV) для взаимодействия с интерфейсами других программ.

## Основные возможности

### 1. Управление окнами
* **Автоматическая расстановка столов:** Расставляет все открытые игровые столы по предопределенным слотам на экране.
* **Динамическая раскладка:** Для QQPoker, если открыто более 4 столов, приложение динамически масштабирует и размещает их для заполнения экрана.
* **Расстановка системных окон:** Автоматически размещает окна лобби, лаунчера клиента и других вспомогательных приложений (например, Camtasia, CV Server) в заданных позициях.
* **Поддержка нескольких проектов:** Имеет разные конфигурации для разных игровых клиентов.

### 2. Автоматизация
* **Автоматическая запись экрана:**
    * Интегрируется с **Camtasia Recorder**.
    * Автоматически **начинает запись** (эмулируя F9), когда обнаруживает активность игровых столов или браузера Chrome.
    * Автоматически **останавливает запись** (эмулируя F10) при отсутствии активности или закрытии клиентов.
    * Отслеживает лимиты сессии (например, 3-5 часов) и автоматически перезапускает запись.
* **Авто-кликер:**
    * **Закрытие спама (Pop-up):** Распознает и автоматически закрывает различные рекламные и спам-окна в клиентах (особенно QQPoker).
    * **Бонусные колеса:** Автоматически обнаруживает и прокручивает бонусные колеса в QQPoker.
    * **Авто-старт:** Нажимает кнопку "Start" в лаунчере плеера.
    * **Авто-эмодзи:** Периодически (со случайным интервалом) нажимает на эмодзи за столами.
    * **Авто-ситаут (ClubGG):** Предоставляет кнопку для автоматического нажатия "Sit Out" или "Sit In" на всех активных столах GG.

### 3. Системная интеграция и Мониторинг
* **Автообновление:** Приложение проверяет наличие новых версий на GitHub (в репозитории `Vater-v/OiHelper`) и может автоматически скачивать и устанавливать обновления.
* **Отправка логов:** При закрытии плеера автоматически запускает батники с рабочего стола (например, `logbot`, `endsess`) для отправки логов.
* **Уведомления Telegram:** Отправляет уведомления о запуске и критических ошибках в личный чат Telegram.
* **Мониторинг аптайма:** Предупреждает пользователя, если компьютер не перезагружался более 5 дней, так как это может привести к сбоям.
* **Очистка процессов:** Принудительно закрывает конфликтующие процессы (такие как `chrome.exe`, `clubgg.exe` и др.) при выполнении определенных действий.

## Поддерживаемые проекты

Приложение имеет встроенные конфигурации для автоматизации следующих клиентов:
* **ClubGG** (проект `GG`)
* **QQPoker** (проект `QQ`)
* **TPuke** (проект `WU`)

## Предпосылки и Зависимости

Для корректной работы OiHelper в системе должны присутствовать:

### Внешнее ПО
* ОС Windows.
* **Camtasia Recorder** (для функции автозаписи).
* Установленные игровые клиенты (ClubGG, QQPoker и др.).
* (Для QQPoker) Запущенный `OpenCvServer.exe`.
* (Для TPuke/WU) Запущенный процесс `run_wukong`.

### Ярлыки на Рабочем столе
Приложение ищет на рабочем столе следующие `.lnk` (ярлыки) для запуска и управления процессами:
* `recorder`: Ярлык для запуска Camtasia.
* `launch`: Ярлык для запуска основного игрового лаунчера.
* `opencv`: Ярлык для запуска OpenCV сервера.
* `run_wukong`: Ярлык для запуска окружения WU.
* `logbot` / `endsess`: Ярлыки для скриптов отправки логов.

### Библиотеки Python
Проект написан на Python и использует следующие основные библиотеки:
* `PyQt6` (для всего интерфейса)
* `requests` (для обновлений и Telegram)
* `psutil` (для управления процессами)
* `pyautogui`, `cv2`, `numpy` (для компьютерного зрения и автоматизации кликов)
* `win32gui`, `win32api`, `win32process`, `win32com.client` (для глубокой интеграции с Windows)

## Установка и Запуск

### Для пользователя (Релиз)
1.  Скачайте последний `OiHelper.zip` со страницы релизов.
2.  Распакуйте архив в удобное место.
3.  Запустите `OiHelper.exe` (предполагаемое имя скомпилированного файла).
4.  Убедитесь, что все необходимые ярлыки (см. раздел "Предпосылки") находятся на Рабочем столе.

### Для разработчика
1.  Клонируйте репозиторий.
2.  Создайте виртуальное окружение: `python -m venv venv`
3.  Активируйте окружение. (Для этого можно использовать `Start.bat`).
4.  Установите зависимости (предположительно `pip install -r requirements.txt`).
5.  Запустите главный скрипт: `python main.py`.

## Структура проекта (основные файлы)

* `main.py`: Весь основной код приложения, включая логику UI, автоматизацию и управление окнами.
* `version.txt`: Файл с указанием текущей версии.
* `Start.bat`: Вспомогательный скрипт для активации `venv` в командной строке.
* `assets/`: Содержит ресурсы интерфейса (`icon.ico`, `splash/splash.png`).
* `templates/`: Содержит PNG-шаблоны для OpenCV, отсортированные по проектам (`GG`, `QQ`, `tpuke`), включая подпапки `emoji` и `sitout`.
* `OiHelperLogs/`: (В `%APPDATA%`) Папка для хранения лог-файлов приложения.
